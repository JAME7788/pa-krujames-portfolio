## คำอธิบายด้าน (วางเป็นข้อความเปิดหน้า)

ข้าพเจ้าพัฒนาตนเองอย่างเป็นระบบและต่อเนื่องตามแผนพัฒนาตนเองรายบุคคล (ID Plan) โดยมุ่งเน้นการยกระดับสมรรถนะด้านเทคโนโลยีดิจิทัลและปัญญาประดิษฐ์ (AI) เพื่อนำมาประยุกต์ใช้ในการจัดการเรียนรู้ และแลกเปลี่ยนเรียนรู้ร่วมกับชุมชนแห่งการเรียนรู้ทางวิชาชีพ (PLC)

## ตัวชี้วัดตามแบบประเมินองค์ประกอบที่ 1 ด้านที่ 3

| ตัวชี้วัด | หลักฐานที่ควรวางในหน้านี้ |
|---|---|
| 3.1 พัฒนาตนเองอย่างเป็นระบบและต่อเนื่อง | ID Plan, เกียรติบัตรอบรม, ชั่วโมงพัฒนาตนเอง และหลักสูตรที่เกี่ยวข้องกับภาษา/เทคโนโลยี/AI |
| 3.2 มีส่วนร่วมในการแลกเปลี่ยนเรียนรู้ทางวิชาชีพ | บันทึก PLC ภาพประชุม วงแลกเปลี่ยนเรียนรู้ และการร่วมกิจกรรมทางวิชาการ |
| 3.3 นำความรู้ ความสามารถ และทักษะจากการพัฒนาตนเองมาใช้ | สื่อ นวัตกรรม แผนการสอน หรือกิจกรรมที่พัฒนาจากความรู้ที่อบรมมา และผลที่เกิดกับผู้เรียน |

## ข้อมูลรายงานองค์ประกอบที่ 3: วินัย คุณธรรม จริยธรรม และจรรยาบรรณ 10 คะแนน

แบบประเมินองค์ประกอบที่ 3 พิจารณาพฤติกรรมการปฏิบัติตน 10 รายการ คะแนนจริงให้ผู้ประเมินพิจารณา แต่เว็บไซต์ควรวางข้อมูลประกอบดังนี้

| รายการประเมิน | ข้อมูลที่ใช้รายงาน | หลักฐานที่ควรแนบ |
|---|---|---|
| 1. ยึดมั่นในสถาบันหลักของประเทศ | เข้าร่วมกิจกรรมหน้าเสาธง วันสำคัญ และกิจกรรมของสถานศึกษา | รูปกิจกรรมหน้าเสาธง/วันสำคัญ/กิจกรรมโรงเรียน |
| 2. ซื่อสัตย์ สุจริต มีความรับผิดชอบ | ปฏิบัติหน้าที่สอน งานโครงการ และงานตามคำสั่งครบถ้วน ส่งเอกสารรายงานตามกำหนด | คำสั่ง รายงานโครงการ ตารางปฏิบัติงาน |
| 3. กล้าคิด กล้าตัดสินใจในสิ่งถูกต้อง | วิเคราะห์ปัญหาผู้เรียนและพัฒนานวัตกรรมเพื่อแก้ปัญหาอย่างเป็นระบบ | รายงานประเด็นท้าทาย บันทึกหลังสอน/PLC |
| 4. จิตอาสาและจิตสาธารณะ | สนับสนุนงานโรงเรียน งานชุมชนสัมพันธ์ งานประชาสัมพันธ์ และกิจกรรมส่วนรวม | รูปกิจกรรมชุมชน ภาพปฏิบัติงานโรงเรียน |
| 5. มุ่งผลสัมฤทธิ์ของงาน | ตั้งเป้าผู้เรียนผ่านเกณฑ์ตาม PA พัฒนาสื่อและติดตามผลก่อน-หลังเรียน | ตารางผลผู้เรียน รายงานผลนวัตกรรม |
| 6. ปฏิบัติหน้าที่อย่างเป็นธรรม | ดูแลผู้เรียนรายบุคคลผ่านระบบดูแลช่วยเหลือ ประสานผู้ปกครอง และคำนึงถึงความแตกต่างของผู้เรียน | แบบคัดกรอง แบบเยี่ยมบ้าน ภาพแนะแนว |
| 7. ดำรงตนเป็นแบบอย่างที่ดี | พัฒนาตนเองต่อเนื่อง มีวินัยในการปฏิบัติงาน และใช้เทคโนโลยีอย่างสร้างสรรค์ | เกียรติบัตรอบรม ภาพกิจกรรม คำรับรอง |
| 8. เคารพศักดิ์ศรีและสิทธิเด็ก | จัดการเรียนรู้ที่ปลอดภัย เหมาะสมตามวัย ส่งเสริมความกล้าแสดงออก และไม่เลือกปฏิบัติ | ภาพกิจกรรมในชั้นเรียน บันทึกดูแลช่วยเหลือ |
| 9. ยึดถือจรรยาบรรณวิชาชีพ | ปฏิบัติงานตามบทบาทครู ใช้ข้อมูลผู้เรียนอย่างเหมาะสม และสื่อสารกับผู้ปกครองอย่างสร้างสรรค์ | คำรับรองผู้บริหาร/หัวหน้ากลุ่มสาระ/PLC |
| 10. มีวินัยและรักษาวินัย | ปฏิบัติตามคำสั่ง ระเบียบราชการ และภาระงานที่ได้รับมอบหมาย | บัญชีลงเวลา คำสั่งเวร/งานมอบหมาย เอกสารราชการ |

## ข้อความสรุปด้านที่ 3 สำหรับรายงาน

ข้าพเจ้าพัฒนาตนเองอย่างเป็นระบบตาม ID Plan โดยเน้นสมรรถนะด้านเทคโนโลยีดิจิทัล AI, ICT, Coding, Active Learning และการวัดผลประเมินผล เพื่อนำความรู้กลับมาใช้ในการจัดการเรียนรู้และพัฒนาผู้เรียนจริง มีการเข้าร่วม PLC 13 ชั่วโมง เพื่อแลกเปลี่ยนเรียนรู้และสะท้อนผลการจัดการเรียนรู้ รวมทั้งนำความรู้จากการอบรมมาสร้างสื่อ นวัตกรรม เกมการเรียนรู้ และเว็บไซต์ E-Portfolio เพื่อยกระดับคุณภาพผู้เรียนและเผยแพร่ผลการปฏิบัติงานอย่างเป็นระบบ

## หลักฐานที่ใช้กับองค์ประกอบที่ 3 รวม 10 คะแนน

แบบประเมินองค์ประกอบที่ 3 พิจารณาการรักษาวินัย คุณธรรม จริยธรรม และจรรยาบรรณวิชาชีพ 10 รายการ ควรวางหลักฐานที่สะท้อนการปฏิบัติตนจริง เช่น การปฏิบัติตามคำสั่งและเวลาราชการ ความรับผิดชอบต่อหน้าที่ จิตอาสา การทำงานเพื่อประโยชน์ส่วนรวม การไม่เลือกปฏิบัติ การคำนึงถึงสิทธิเด็ก การรักษาภาพลักษณ์ของข้าราชการครู และการยึดถือจรรยาบรรณวิชาชีพ

## การนำผลการพัฒนามาใช้

- นำความรู้จากหลักสูตร AI for Teachers มาออกแบบสื่อ เกม และเครื่องมือประเมินผล
- นำเทคนิค Gamification และ Quizizz มาใช้แก้ปัญหาในชั้นเรียนจริง (ดูด้านที่ 1)
- นำความรู้ Unplugged Coding มาจัดกิจกรรมวิทยาการคำนวณสำหรับนักเรียนประถม
- เข้าร่วมชุมชนแห่งการเรียนรู้ทางวิชาชีพ (PLC) **13 ชั่วโมง/ปี** และงานตอบสนองนโยบายและจุดเน้น **10 ชั่วโมง** (ตาม ID Plan 2568)
