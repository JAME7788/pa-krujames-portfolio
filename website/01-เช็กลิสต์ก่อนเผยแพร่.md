# เช็กลิสต์ก่อนเผยแพร่ Google Sites

ไฟล์นี้ใช้รับช่วงงานต่อจากชุด `content/` และ `embeds/` เพื่อเช็กข้อมูลจริงก่อนเผยแพร่เว็บ E-Portfolio/PA

## 1. โครงสร้างหน้าเว็บ

- [ ] สร้างเมนู Google Sites ให้ครบ **8 หน้าแสดงผลหลัก**
- [ ] หน้า 1: หน้าแรก
- [ ] หน้า 2: ประวัติส่วนตัว
- [ ] หน้า 3: ด้านที่ 1 การจัดการเรียนรู้
- [ ] หน้า 4: ด้านที่ 2 การส่งเสริมและสนับสนุน
- [ ] หน้า 5: ด้านที่ 3 การพัฒนาตนเองและวิชาชีพ
- [ ] หน้า 6: ผลงานเด่นและรางวัล
- [ ] หน้า 7: เอกสารการประเมิน เป็นหน้าหลักสำหรับเปิดตรวจตามแบบประเมินเลื่อนเงินเดือน
- [ ] หน้า 8: นวัตกรรมและวิจัยในชั้นเรียน
- [ ] หน้า `ประกวดเว็บครู.ไทย` ซ่อนจากเมนูนำทางแล้ว และย้ายข้อมูลสำคัญไปหน้าอื่นตามความเหมาะสม

## 2. ข้อมูลที่ต้องยืนยันจากหลักฐานจริง

- [ ] วันที่แต่งตั้งให้ดำรงตำแหน่ง **ครู อันดับ คศ.1** ยังไม่พบคำสั่งแต่งตั้งในโฟลเดอร์ที่ตรวจ จึงไม่ควรระบุวันแน่นอนบนเว็บ
- [x] เงินเดือนอันดับ คศ.1 ปัจจุบันใส่ไว้เป็น `20,250 บาท` ตามแบบ PA
- [ ] รอบประเมินตามแบบเลื่อนเงินเดือน: ครั้งที่ 1 (1 ต.ค.-31 มี.ค.) หรือ ครั้งที่ 2 (1 เม.ย.-30 ก.ย.)
- [ ] จำนวนวันลาในรอบประเมิน: ลาป่วย ลากิจ และลาอื่น ๆ ถ้ามี
- [ ] คะแนนประเมินตนเองและคะแนนผู้บังคับบัญชาในองค์ประกอบที่ 1, 2 และ 3
- [ ] หลักสูตร `การสร้างเว็บไซต์ด้วยชื่อโดเมน .th และ .ไทย` วันที่ `22 พ.ค. 2569` ยังไม่พบเกียรติบัตรในโฟลเดอร์ `maiyakyoo`; อย่านับชั่วโมงจนกว่าจะมีหลักฐาน
- [ ] โดเมนภาษาไทยของเว็บไซต์แสดงเป็น `เอเจเจ.ไทย` และเปิดได้จากภายนอก
- [ ] ข้อความสัญญาอนุญาตแบบเปิด เช่น `CC BY-NC-SA 4.0` แสดงในเว็บไซต์
- [ ] ข้อความหลักการใช้ AI อย่างมีจริยธรรมแสดงในเว็บไซต์
- [ ] ชื่อรางวัลผู้ฝึกสอนนักเรียนปี 2567 ให้ตรงกับเกียรติบัตรจริง
- [ ] ผลสัมฤทธิ์/ผลทดลองใช้นวัตกรรม ภาคเรียนที่ 1/2569 หลังสิ้นภาคเรียน

## 4. รูปภาพที่ควรเตรียม

- [ ] รูปโปรไฟล์ครูเจมส์แนวตั้ง 3:4
- [ ] รูปหน้าโรงเรียน/ป้ายโรงเรียนแนวนอน
- [ ] รูปการจัดการเรียนรู้ในห้องเรียน 2-4 รูป
- [ ] รูปสื่อ/นวัตกรรมเด่น 2-4 รูป
- [ ] ภาพหน้าจอ Gamification ป.1 และ Quizizz ม.3
- [ ] รูปเยี่ยมบ้าน/ประชุมผู้ปกครอง/ลูกเสือ/ชุมชน
- [ ] รูปเกียรติบัตรอบรมและรางวัล
- [ ] รูปปกเอกสารหลักฐานแต่ละเล่ม
- [ ] ภาพหน้าจอเว็บไซต์บนคอมพิวเตอร์และมือถือสำหรับหน้า `ประกวดเว็บครู.ไทย`
- [ ] QR Code เว็บไซต์หลังเผยแพร่
- [ ] ถ้ายังใช้ภาพประกอบ AI ในหน้าใด ให้แสดงคำว่า “ภาพประกอบที่สร้างด้วย AI” ชัดเจน
